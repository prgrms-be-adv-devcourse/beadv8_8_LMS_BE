# 범위

채팅 앱 작업의 포함·제외 범위다.

- chat-app은 **replica 1개**를 기준으로 설계·구현·테스트·배포한다(사용자 결정, 2026-10-29). 여러 사용자와 동일 회원의 여러 WebSocket 연결은 한 앱에서 처리한다. 복수 replica 배치·전달·연결 종료 시험은 이번 범위에서 제외한다.

- 현행 구현은 1:1 채팅이며, **이번 고도화의 설계·구현 범위에 단체(그룹) 채팅을 포함한다**(사용자 결정, 2026-10-29). `GROUP` 타입·도메인·API·마이그레이션·FE·관리자 기록·테스트를 작업 범위에 넣는다. 단체채팅 포함 여부를 다시 승인받거나 후속 과제로 미루지 않는다.
- 출연 알림(`AppearanceNotificationEventListener`)은 알림 모듈·FE 이관이 끝나기 전에 제거하지 않는다 (설계 문서 5.5).
- 설계 문서 8장의 미정 항목은 추측으로 정하지 않는다. 단체채팅 범위 확정과 세부 정책(Q1~Q5·Q10) 확정을 구분하며, 미정 정책·FE 계약은 해당 구현 전에 확정하고 결과를 설계 문서와 용어·정책에 남긴다. 이미 확정한 사항은 다시 승인받지 않는다.
