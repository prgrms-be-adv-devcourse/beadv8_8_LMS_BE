# 도메인

## 용어와 책임

| 용어 | 의미 |
| --- | --- |
| 쿠폰 정책 | 대상 강의·할인·수량·기간·중첩 여부를 가진 발행 단위 |
| 발급 쿠폰 | 회원이 받은 한 장. 회원당 같은 정책에서 1장 |
| 신청자 | 판매자 쿠폰을 신청한 판매자. 플랫폼 쿠폰은 관리자가 발행한다 |
| 쿠폰 유형 | SELLER / PLATFORM. 할인 비용 부담 기준 |
| 사용 시도 | 발급 쿠폰 ID + generation. 주문 항목 하나에 연결 |
| 발급 요청 | issueRequestId로 식별하는 선착순 접수와 확정 결과 |
| 프로모션 예산 | 플랫폼이 충전한 프로모션 지갑에서 쿠폰에 예약한 재원 |

쿠폰은 정책·발급·계산·예약·복원을, 강의는 주문·구매·취소·지급 시점을, billing은 재원 충전·보류·반환·지급·원장을 소유한다.

## 비용 부담

10,000 HP 강의에 10% 할인 쿠폰을 적용한 예다.

| 유형 | 구매자 부담 | 플랫폼 부담 | 판매자 지급 |
| --- | ---: | ---: | ---: |
| 판매자 쿠폰 | 9,000 | 0 | 9,000 |
| 플랫폼 쿠폰 | 9,000 | 1,000 | 10,000 |

판매자 쿠폰은 판매자의 지갑에서 선납하지 않는다. 플랫폼 쿠폰은 관리자만 발행하며 플랫폼 재원 확보가 필요하다. 판매자는 플랫폼 쿠폰을 신청할 수 없다.

항목 원가격 P, 쿠폰별 실제 할인 d, 플랫폼 부담 f, 판매자 부담 s를 기록한다.

- 쿠폰별 d = f + s.
- 항목 D = Σd, F = Σf, S = Σs.
- 구매자 결제액 = P − D ≥ 0.
- 판매자 지급액 = P − S = 구매자 결제액 + F.
- 판매자 쿠폰은 f = 0, 플랫폼 쿠폰은 s = 0.
- 정률은 적용 직전 해당 강의의 남은 금액에 적용하고 1 HP 미만은 버린다(`floor`). 정액도 남은 금액까지만 할인한다. 정액이 강의 가격보다 커도 발행·사용할 수 있으며 그때 결제액은 0 HP다. 모든 강의 대상 정률 쿠폰은 장당 최대 할인액을 넘지 않는다.
- 쿠폰 한 장은 한 번 사용하면 사용 완료다. 잘려 적용된 차액을 쿠폰 잔액으로 남기지 않는다.

지급은 기존 강의 지급 조건이 충족된 뒤 이루어진다. 결제 순간 판매자에게 지급하지 않는다. 원가격·구매자 결제액·판매자 지급액을 서로 다른 값으로 보존한다.

## 대상과 기간

판매자 쿠폰은 본인 특정 강의에만 적용한다. 플랫폼 쿠폰은 특정 강의 또는 모든 강의 중 하나에 적용한다. 후자는 주문 전체 쿠폰이 아니다. 한 발급 쿠폰을 여러 항목에 중복 배치하지 않는다.

고정 만료 시각과 접수 시각 + N일을 지원한다. 최초 접수 때 issuedAt·expiresAt을 확정하고 재전송으로 연장하지 않는다. 모든 기간 비교는 Instant로 하고 업무 날짜 표현은 KST를 따른다. 유효 조건은 expiresAt > now다.

## 상태

| 대상 | 상태·전이 |
| --- | --- |
| 판매자 신청 정책 | DRAFT → REVIEW → OPEN / REJECTED |
| 관리자 자체 생성 | DRAFT → OPEN |
| 발급 운영 | OPEN → SUSPENDED → OPEN(재개) / CLOSED. OPEN·SUSPENDED → CLOSED. OPEN이어도 예산·Redis 준비 전에는 접수 불가 |
| 발급 쿠폰 | AVAILABLE → RESERVED → USED |
| 예약 실패 보상 완료 | RESERVED → AVAILABLE 또는 EXPIRED |
| 취소·반환 완료 | RESERVED 또는 USED → AVAILABLE 또는 EXPIRED |

발급 중단과 이미 발급된 쿠폰의 사용 금지는 다른 정책이다. 기존 발급분 회수·조건 변경 규칙은 미확정이며 자동 회수하지 않는다.

**가격 인상 제한:** 특정 강의를 대상으로 한 플랫폼 쿠폰이 `OPEN`이거나 그 쿠폰의 미사용(`AVAILABLE`·`RESERVED`) 발급 쿠폰이 남아 있는 동안 강의 모듈은 그 강의의 가격 인상을 거부한다. 올리려면 관리자가 쿠폰을 종료하고 남은 발급 쿠폰을 만료 처리한 뒤 올린다. 판매자 쿠폰은 판매자 손해이므로 제한하지 않고, 가격 인하도 제한하지 않는다(예산은 상한이라 남는다). 모든 강의 대상 플랫폼 쿠폰은 이 제한을 걸 수 없으므로 예산 기준을 따로 정한다(decisions.md).

취소 요청만으로 복원하지 않는다. 반환·예산 복구 완료를 확인하고 복원 시점의 유효기간을 검사한다. 취소 완료 뒤 늦게 온 결제 완료는 사실만 기록한다. 이전 generation의 이벤트는 현재 사용 상태를 바꾸지 않는다. 만료가 과거 구매의 할인 효력을 취소하지 않는다.
