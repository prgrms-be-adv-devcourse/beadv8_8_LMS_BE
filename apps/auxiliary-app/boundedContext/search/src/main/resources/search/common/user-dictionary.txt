# nori 사용자 사전(#771). 한 줄에 한 단어, 한 단어 규칙 + decompound_mode=discard다.
# 검색 index 모두가 함께 쓴다(#868). 바꾸면 그 index들이 모두 재색인한다.
# 사전이 없으면 사라지거나(치지직·옵치) 뜻이 깨지는(인플루언서 → 인/플/언서, 배그 → 배) 단어만 넣는다. 근거는 _analyze 시험(옵시디언 15 검색 ES 시험 보고서 3장).
# 띄어 쓴 이름(리그 오브 레전드, FC 온라인)은 사전으로 붙일 수 없어 동의어(synonyms.txt)가 맡는다.
# 뜻 있는 두 낱말이 붙은 합성어(컷편집 → 컷/편집, 영상편집)는 넣지 않는다. 넣으면 한 토큰이 되어 "편집"·"컷 편집"으로 찾지 못한다(#895).
# 이 파일을 바꾸면 index 설정 해시가 바뀌어 재색인이 필요하다(#773). 빈 줄과 #으로 시작하는 줄은 읽지 않는다.
