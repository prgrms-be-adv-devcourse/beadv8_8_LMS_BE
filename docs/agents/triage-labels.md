# 트리아지 라벨

스킬은 트리아지 역할 다섯 가지로 말한다. 이 파일은 그 역할을 이 레포의 실제 라벨 이름에 연결한다.

| mattpocock/skills 라벨 | 이 레포 라벨 | 뜻 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 담당자가 검토해야 한다 |
| `needs-info` | `needs-info` | 작성자의 추가 정보를 기다린다 |
| `ready-for-agent` | `ready-for-agent` | 명세가 끝나서 에이전트가 혼자 처리할 수 있다 |
| `ready-for-human` | `ready-for-human` | 사람이 구현해야 한다 |
| `wontfix` | `wontfix` | 처리하지 않는다 |

스킬이 역할을 말하면(예: "AFK 준비 완료 라벨을 붙인다") 위 표의 라벨 이름을 쓴다.

레포가 다른 이름을 쓰게 되면 "이 레포 라벨" 열을 고친다.
